# CCNA Study Lab

Practice: https://mushincode.github.io/ccna-study-pwa/

1395 source questions; 806 reviewed, 670 scoreable, 589 awaiting review. Reviewed defective questions explain the issue and are not scored. English and Traditional Chinese explanations, detailed image descriptions, lab configuration/verification guides, and 718 Anki cards are included.

Answer records stay in each browser and are not published. Automatic cross-device sync is not implemented. Scheduling and Codex reminders were removed at the user's request.

Deployment validates all question assets before publication.
