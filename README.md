# CCNA Study PWA

Practice: https://mushincode.github.io/ccna-study-pwa/

English questions with available Traditional Chinese translations and selectable English/Chinese explanations. Single choice, multiple choice, image questions, drag-and-drop and reference labs are supported. Mock exams use one minute per scored question and can be cancelled without a score.

## Current content

The published snapshot contains 1,395 questions from the user's supplied PDFs and their image assets. 253 questions have completed individual review; 171 have independently checked, unambiguous answers suitable for scoring. The remaining translations and explanations are still being reviewed. Defective or pending questions are excluded from scored mock exams. This is a practice bank, not an official Cisco exam or a passing-score prediction.

## Install and save progress

- iPhone: open in Safari → Share → Add to Home Screen.
- Mac: open in Safari → Add to Dock.
- Questions and the app shell are cached after an online load. Images and downloads become available offline after being viewed/downloaded.
- Answer records and settings are saved in the current browser only. Export/import a backup in Study settings to transfer progress between devices. GitHub Pages does not provide automatic cloud sync.
- Reset requires two confirmations and downloads a recovery backup first.

No personal answer history, account credentials or complete PDF files are published.

## Deployment

The three release archives contain the static app/question JSON and two sets of image assets. `.github/workflows/deploy.yml` assembles and validates them before publishing to GitHub Pages. The app source is included in `pwa-app.zip`; no build dependencies or server are required. Future reviewed snapshots can replace the release archives and deploy automatically.
