# CCNA Study Lab

Practice: https://mushincode.github.io/ccna-study-pwa/

1395 source questions; 613 reviewed, 497 scoreable, 782 awaiting review. Reviewed defective questions explain the issue and are not scored. English and Traditional Chinese explanations, detailed diagram descriptions, and 545 Anki cards are included in this release.

Answer records remain in each browser and are not published. Automatic cross-device sync is not implemented. Scheduling and Codex reminders were removed at the user's request.

The deployment workflow unpacks the app and image archives and validates question assets before publishing.
