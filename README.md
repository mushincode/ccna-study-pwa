# CCNA Study Lab

Practice: https://mushincode.github.io/ccna-study-pwa/

1395 source questions; 722 reviewed, 593 scoreable, 673 awaiting review. Reviewed defective questions explain the issue and are not scored. English and Traditional Chinese explanations, detailed diagram descriptions, lab configuration/verification guides, and 641 Anki cards are included.

Answer records remain in each browser and are not published. Automatic cross-device sync is not implemented. Scheduling and Codex reminders were removed at the user's request.

The deployment workflow validates question assets before publishing.
